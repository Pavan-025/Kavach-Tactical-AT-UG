# Kavach-Tactical-AT-UG
The Kavach Bot is a defense-inspired All-Terrain UGV built for remote tactical reconnaissance. It utilizes a decentralized architecture, combining an nRF24L01 RF link for zero-latency tracked mobility, an ESP32-CAM for asynchronous Wi-Fi video streaming, and IoT-linked acoustic radar for precise obstacle mapping in GPS-denied combat environments.
